## Что умеет

- **Анимация тока.** Точки на проводах показывают направление и момент протекания тока, цвет провода — тип напряжения. Ключи открываются и закрываются, диоды проводят по очереди.
- **Два вида.** «Схема» — принципиальная схема по участкам. «Плата» — детали в настоящих корпусах, сгруппированные по узлам, с медными дорожками между выводами. На плате тоже видно ток: дорожки окрашены по напряжению, по работающим цепям бегут точки. На плате видны повреждения, заметные глазом: вздутые конденсаторы, обгоревшие резисторы, тёмный предохранитель, трещины.
- **Подсветка цепей.** Выбранная деталь подсвечивает все провода и детали, с которыми она соединена, остальное приглушается.
- **Поиск детали** по позиции, названию или номиналу (клавиша `/`).
- **Режим «Обучение».** Любую деталь можно вывести из строя. Карточка объясняет, почему цепь перестала работать, какие будут признаки и почему деталь обычно выходит из строя.
- **Приборы.**
  - Мультиметр: V⎓, V~, Ω, прозвонка, диод, ёмкость.
  - ESR-метр.
  - Осциллограф: форма сигнала на выбранном выводе.
  - Тестер деталей: только для выпаянной детали в корзине.
  - Тепловизор: показывает нагрев деталей.
  - Сопротивление и диоды меряются только на обесточенной плате с разряженным C1.
  - Под каждым показанием — значение на исправной плате и отметка «в норме / не в норме». На осциллографе эталон показан пунктиром. В экзамене подсказки скрыты.
  - Блокнот: все измерения записываются в таблицу с нормой, по ней видно ход диагностики.
- **Лабораторный БП.** Подаёт напряжение на шину при выдернутой вилке. При КЗ на шине срабатывает ограничение тока, а тепловизор показывает, какая деталь греется.
- **Лампа 100 Вт.** Включение в сеть через лампу: при КЗ лампа горит ярко, а предохранитель остаётся цел.
- **Режим «Ремонт».**
  - Задачи со скрытой поломкой, цепочки поломок (если устранить только следствие, деталь сгорит снова), случайные поломки на 1 или 2 детали.
  - Подсказки открываются по одной, как шаги маршрута; детали в подсказках кликабельны и показываются на схеме.
  - Деталь перетаскивается в корзину и проверяется. Замена перетаскивается из каталога. Неподходящая деталь не помогает или сгорает.
  - **Экзамен:** 5 случайных поломок подряд, без подсказок, на время, с итоговой оценкой.
  - Очки, звёзды и история ремонтов. Незаконченная задача сохраняется в браузере и продолжается после перезагрузки.
- **Шпаргалка** по устройству: признак → какие детали и какая поломка (можно распечатать).
- **Прогресс:** решённые задачи по всем устройствам, оценки за экзамен, список задач «стоит повторить».
- **Маршрут диагностики** в режиме ремонта: универсальный порядок проверки «да / нет», ответ задачи он не раскрывает.
- **Пауза** (кнопка или пробел): схема и ток замирают, можно спокойно всё рассмотреть и измерить.
- **Горячие клавиши** (`?` — список), **тема** светлая / тёмная / как в системе, короткий тур **«Как пользоваться»** при первом открытии.
- **Шаг назад** свайпом слева направо или кнопкой «‹ Назад»: закрывает окно, возвращает на предыдущую вкладку.
- **Блокнот** копируется как текст — удобно вставить в заметки.
- **Звуки:** хлопок при КЗ, тиканье, щелчки реле, писк прозвонки.
- **Телефон.** Внизу вкладки «Схема / Деталь / Приборы / Устройство / Задача», показание прибора видно поверх схемы. Касание выбирает деталь; выпайка — кнопкой в карточке, установка — касанием в каталоге.
- **Установка как приложение.** С сайта на GitHub Pages страницу можно установить на телефон или компьютер; после первого открытия работает без интернета.

## Как запустить

Откройте `index.html` в браузере, сервер не нужен. Онлайн-версия — через GitHub Pages: `https://nemec8912-eng.github.io/PSU-simulator/`.

Чтобы собрать страницу в один файл (например, отправить кому-то): `python3 tools/build.py adapter.html dist/adapter.html`.

## Как развивать

**Добавить задачу.** Допишите объект в `SCEN` в `boards/<плата>/scenarios.js`:

```js
{t:"Короткое название", c:"Жалоба владельца", F:{C7:"dry"}, fuse:false,
 h:["Подсказка 1","Подсказка 2","Подсказка 3"], a:"Правильный ответ"}
```

`F` — какие детали неисправны и как (`open`, `short`, `dry`, `dead`, `drift`, `stuck` — залипшие контакты реле или микровыключателя). Для цепочки добавьте `chain:1`. Каскад, который убивает деталь повторно, описывается в `CASC` в `sim.js`.

**Добавить поломку детали.** В `parts.js` у детали в последнем объекте добавьте режим `[почему не работает, [признаки], почему выходит из строя]`. Затем учтите его в `sim()`. Если поломка должна попадать в случайные задачи, добавьте пару `["ID","режим"]` в `RANDOM_POOL`.

**Добавить деталь.** Опишите её в `parts.js`, поставьте на участок в `schematic.js` (тип, координаты выводов `a`/`b`), подключите провода (`w`) к цепи. Для приборов добавьте выводы в `PINS` (`probe.js`). На виде «Плата» деталь появится сама.

**Добавить новую плату.**
1. Скопируйте папку `boards/adapter` (или самую похожую) в `boards/<новая>` и перепишите шесть файлов.
2. Добавьте плату в `tools/boards.json` (имя файла, заголовок, тексты кнопок, группа и значок для меню) и запустите `python3 tools/pages.py` из корня проекта. Скрипт создаст `<новая>.html` и добавит её в меню «Устройства» на всех страницах.
3. `sim()` должна заполнять `S.devOK` — устройство работает правильно. По нему засчитывается ремонт. Если плата должна сначала пройти цикл (как стиральная машина), задайте ещё `S.winReady`.

Предохранитель должен называться `F1`. Опасный конденсатор, который разряжают перед измерениями, по умолчанию `C1`; другое имя задаётся в `BOARD.capName` (у микроволновки это `C3`). Типы деталей определяются по имени: `SW` — выключатели, `MG` — магнетрон, `M` — двигатели, `J` — разъёмы, `BT` — аккумуляторы, `RL` — реле, `TR` — симисторы.

## Оговорка

Схемы собраны по типовым архитектурам, номиналы и позиционные обозначения типичные — на конкретной плате они отличаются. Модель учебная, это не SPICE-симуляция.
