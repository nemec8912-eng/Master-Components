# Master Toolkit — Живая лаборатория

Три проекта мастера в одном приложении с общим стартовым экраном:

| Карточка | Папка | Что это |
|---|---|---|
| **Master Diagnose Pro** (синяя) | `diagnose/` | Справочник диагностики и ремонта бытовой техники: поиск по симптому и коду ошибки, алгоритмы, чек-листы, замеры, журнал ремонтов. |
| **Electronic Lab** (оранжевая) | `components/` | Master Components — справочник радиокомпонентов: виды, маркировка, проверка мультиметром, исправные и неисправные показания, экзамен, SMD-коды, калькуляторы. |
| **PSU Simulator** (зелёная) | `psu/` | Симулятор ремонта электроники: живые анимированные схемы блоков питания и плат (Samsung BN44 и ещё 12), неисправности, щупы, режим ремонта. |

**Открыть:** https://nemec8912-eng.github.io/Master-Components/

Работает в браузере на компьютере, Android и iPhone. Можно добавить на главный экран — откроется как приложение и будет работать без интернета (все три проекта кэшируются).

## Как устроено

- `index.html` — стартовый экран «Живая лаборатория»: три левитирующие карточки над энергетическими кольцами. Нажатие в любом месте карточки открывает проект. Сверху в открытом проекте — панель переключения между проектами и кнопка «Домой».
- Проекты подключаются как есть, каждый в своей папке, и открываются внутри оболочки. Их файлы не изменены (кроме одной строки в `components/sw.js`: кэш Master Components теперь удаляет только свои старые версии, чтобы не стирать кэш соседних проектов).
- Каждый проект можно открыть и отдельно: `…/diagnose/`, `…/components/`, `…/psu/`.
- `sw.js` в корне кэширует только стартовый экран; у каждого проекта свой service worker.

## Источники проектов

- Master Diagnose Pro — репозиторий `nemec8912-eng/Master-Diagnose-Pro` (файлы сайта по списку из `scripts/build.cjs`).
- PSU Simulator — репозиторий `nemec8912-eng/PSU-simulator`.
- Master Components — этот репозиторий (до объединения — ветка `backup-before-merge`).

Чтобы обновить Diagnose Pro или симулятор, скопируйте новые файлы из их репозиториев в `diagnose/` или `psu/`.

## Master Components: как добавить или поправить компонент

Данные лежат в `components/js/data/*.js`. Формат описан в начале `components/js/data/00-core.js`. После изменений увеличьте `VERSION` в `components/sw.js`.
